# Tona Café ☕

A modern, responsive landing page and interactive web application for **Tona Café**.

## Features

- **Cozy Editorial Aesthetic**: Typography with *Fraunces*, *Manrope*, and *DM Mono*.
- **Interactive Menu (18 Items across 4 categories)**:
  - ☕ Coffee & Brews
  - 🍵 Teas & Coolers
  - 🥐 Artisan Bakery
  - 🥪 Brunch & Plates
- **Milo the Barista Cat**: An interactive animated SVG mascot that wiggles its ears, blinks, and serves hot recommendations with steaming coffee.
- **Order Ahead & Cart**:
  - Live floating order bar.
  - Interactive checkout modal with item quantity adjusters (`+`/`-`), pickup time selector, and contact details.
- **Dark & Light Mode**: Seamless theme toggle with `localStorage` memory.
- **Responsive & Mobile Ready**: Hamburger navigation drawer and responsive layout for all screens.

## Quick Start

Open `index.html` directly in any web browser, or run the built-in PowerShell server:

```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```

Then visit [http://localhost:8080/](http://localhost:8080/) in your browser.
